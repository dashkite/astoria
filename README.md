# Dashkite Astoria

*Models and controllers for Central Park*

[![Hippocratic License HL3-CORE](https://img.shields.io/static/v1?label=Hippocratic%20License&message=HL3-CORE&labelColor=5e2751&color=bc8c3d)](https://firstdonoharm.dev/version/3/0/core.html)

Astoria provides a collection of domain-specific models and controllers (such as auth, blog, and profile) built using the Chicago RMVC architecture.

## Installation

Use your favorite package manager:

```bash
npm install @dashkite/astoria
```

## Usage

Import the models or controllers you need for your application.

```coffeescript
import { Controllers, Models } from "@dashkite/astoria"
```

## Status

Not suitable for production use. Please report any issues on the [GitHub repository](https://github.com/dashkite/astoria).
